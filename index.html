Explore cheap Bluetooth devices SHWM BLE Scanner & ESPHome Generator v0.4

Discover advertisements from affordable Bluetooth scales, thermometers and other BLE gadgets — no vendor app or cloud account required for supported broadcasts. Recognizing a device is not the same as having ESPHome YAML: our LC026 scale is currently the only profile with independently verified YAML generation.

Before flashing: the initial BLE Scanner replaces any firmware already on your ESP32. Back up an existing ESPHome configuration first. Use a spare board when possible. Only click Install on the correct USB device.

Step 4 · Paste YAML into ESPHome and install

  1. Click Copy YAML above and open ESPHome Device Builder.
  2. Create/edit your ESP32 device, open its YAML editor, and paste the generated YAML instead of the starting example. Match the board selected in Step 1.
  3. Set your Wi-Fi, API and OTA values in secrets.yaml, click Validate, then Install → Manual download to compile the final firmware.
  4. Disconnect the live scanner. Flash the compiled firmware using ESPHome's supported USB method or ESPHome Web. Add the ESPHome device in Home Assistant.

Remember: installing ESPHome replaces the temporary scanner. ESPHome Web does not compile YAML; compilation happens in Device Builder. Choosing an ESP32 board alone cannot generate code for unknown Bluetooth devices.
