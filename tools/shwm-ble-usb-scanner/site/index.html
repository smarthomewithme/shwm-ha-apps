Before flashing: the initial BLE Scanner replaces any firmware already on your ESP32. Back up an existing ESPHome configuration first. Use a spare board when possible. Only click Install on the correct USB device.

Step 1 · First time? Install the BLE Scanner

Plug a supported ESP32 board into your computer with a USB data cable. In Chrome or Edge, click Install BLE Scanner and confirm the correct USB/COM port. This is a temporary program that receives raw BLE advertisements and prints them over USB; it does not require Wi-Fi or the original product app.

Step 2 · Connect via USB and scan live

After installing the scanner, reconnect to the USB port. Click Connect and scan live, choose the same serial device and turn on your BLE gadget (for a scale, step on it). New readings should appear below without copying logs. Web Serial needs HTTPS and your permission.

Currently, only the validated LC026 profile has an ESPHome YAML template. Theengs decodes recognized device packets live, but its decoded object is not automatically an ESPHome driver. YAML sensor generation is deliberately restricted to verified protocols.

Step 4 · Replace scanner with final ESPHome firmware

Go to ESPHome Device Builder. Create a node for your exact ESP32 model. Replace the initial sample text in the YAML editor with the YAML generated above, set your local secrets (Wi-Fi, API key and OTA password), then use Validate and Install → Manual download to compile and obtain the final firmware.

Disconnect the live scanner first so the USB port becomes available. Flash the compiled image using the Device Builder's supported USB process or ESPHome Web. This second installation overwrites the temporary scanner automatically; do not manually erase the chip. Then add the ESPHome device in Home Assistant. ESPHome Web alone does not compile YAML.
